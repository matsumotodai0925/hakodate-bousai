# 函館市防災ダッシュボード

八雲町情報政策室のブログ記事「緊急地震速報をきっかけに」で紹介された防災ダッシュボードを、函館市向けにブラウザだけで動く形で作りました。

`index.html` を開くだけで使えます。サーバーやインストールは要りません。

## 表示する内容

- 最新の地震情報(P2P地震情報)
- 函館市内の震度観測点7点の震度(地図と表)
- 津波情報(津軽海峡沿岸、北海道太平洋沿岸西部)
- 函館市の気象警報・注意報
- 市内各地(函館、川汲、戸井泊)の現在の気温、風、降水量、積雪(アメダス)。地図の右側に表示します
- 地図の上の雨雲レーダー(気象庁の高解像度降水ナウキャスト)。30分前の実況から約1時間後の予測まで、再生とスライダーで動かせます
- 強震モニタへのリンク(最新の地震情報の中)
- 各データ源の通信状態(それぞれのカードの下に表示)

新しい地震情報を受け取ったときは、画面上部に帯を出し、通知音をオンにしていれば音も鳴らします。

## 地震モード

函館市で震度1以上、または全国で震度5弱以上の地震があると、その地震から30分間、自動で地震モードに切り替わります。最新の地震情報、津波情報、震度観測点の地図と表だけを大きく表示し、天気と雨雲レーダーは隠します。画面上部の「通常の表示に戻す」で、すぐに戻せます。条件は `CFG.eqMode` で変えられます。

## 試験モード

ヘッダーの「試験モード」を押すと、函館市で震度6弱を観測した架空の地震と、津波注意報、大雨警報の表示に切り替わります。地図の観測点も、架空の震度で色が変わります。試験中は紫色の帯を出し、本物の情報と区別します。

## 設定

`index.html` の先頭付近にある `CFG` で、市町村コード、アメダス地点、震度観測点、津波予報区、更新間隔を変えられます。

## 震度観測点

`CFG.stations` に、美原、大森町、日ノ浜町、泊町、新浜町、川汲町、尾札部町の7点を入れています。美原と尾札部町の位置は気象庁の観測点一覧の緯度経度です。ほかの5点は自治体が設置した観測点で、位置は町名の代表点(国土地理院の住所検索)です。実際の設置場所とはずれます。

## 注意

- 確認と補助のための画面です。避難の判断は、J-ALERT、防災行政無線、気象庁の発表を優先してください。
- 函館市の沿岸は津軽海峡と噴火湾にまたがるため、津波は2つの予報区を表示します。予報区の割り当ては気象庁の公式資料で確認していません。
- P2P地震情報と気象庁のデータは、外部サービスです。取得できないときは通信状態の欄に失敗と出ます。

## 使い方

`index.html` をダウンロードして、ブラウザで開きます。サーバーやインストールは要りません。非公開リポジトリのままでも使えます。職場の共有フォルダや社内サーバーに置いても動きます。インターネットに接続できることが必要です。
